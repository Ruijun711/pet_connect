# 🐾 Pet Connect｜寵物配對

> 養寵物前的決策工具 —— 每個功能都回答同一個問題：**「我適不適合養這隻寵物？」**

課堂專題｜AI 軟體工程（AIPE）｜範圍：台灣、狗與貓｜時程：2026/11/27 – 2027/1/21（約 8 週）｜提案版本：v0.6

🔗 **網頁展示**：https://ruijun711.github.io/pet_connect/
　（目前為小組討論用的測試版，資料皆為示意）

---

## 專案概述

一個專門解決「養寵物決策」的 AI：使用者在單一輸入框用一句話說出自己的狀況、住的地方或疑問（例如「我是新手，住大安區的公寓，柯基可以嗎？」），AI 會推薦適合的狗或貓、說明原因、補問缺少的資訊並回答問題，全部只依據本站的台灣在地資料並附來源。每個品種頁提供介紹、特徵、照顧方式與費用，並把「購買幼犬」與「領養」並列，讓使用者自己比較。

## 要解決的問題

- 想養寵物的人不清楚哪種品種適合自己的生活條件
- 不清楚購買價格、每年開銷與照顧需求
- 買和領養的資訊分散，難以比較
- 不清楚自己的居住環境適合養哪種寵物

## 為什麼值得做

- **市場**：台灣寵物市場已突破新臺幣 800 億元；114 年推估家犬 146 萬隻、家貓 174 萬隻，家貓兩年增加 32.8%
- **痛點**：多數人養之前沒有準備好 —— 61% 飼主認為開銷比預期高、同樣 61% 沒有事先研究費用（美國 ValuePenguin）
- **依據**：針對 444 位台灣狗主人的研究發現，飼主的知識與動機是成功飼養最強的預測因素；準備較充分者會選擇較合適的取得管道、行為問題也較少
- **缺口**：目前沒有找到在台灣同時提供「品種推薦＋費用＋購買與領養比較」的網站

> 本專案不宣稱「配對可降低棄養」，而以「幫助使用者在養之前做足準備」為主要論點。詳細來源見 [`brief.md`](brief.md) 第 1、2 節。

## 差異化

1. **自然語言搜尋**：AI 會追問、可逐步追加條件，不是固定問卷
2. **台灣在地化**：新台幣價格、台灣法規、台灣收容所資料、台北市周邊設施
3. **購買與領養同頁比較**，不偏向任何一邊
4. **與通用 AI（ChatGPT、Claude）不同**：只依台灣在地資料並附來源，能直接連到可行動的資訊（收容所動物、合法業者名冊），並以實驗量化可靠度
5. **陪伴等待期**：符合條件的收容動物上架時主動通知，並讓家人能一起討論，避免「用完就走」

### 功能 1：寵物配對 AI

> 使用者輸入：「我是新手，住大安區的公寓，柯基可以嗎？」

AI 讀出**條件**（新手、公寓）、**地點**（大安區）、**問題**（柯基可以嗎？），並在同一個畫面回應：

1. **回答問題（附來源）**：柯基可以住公寓，但吠叫較多、運動量大
2. **推薦品種卡片**：依條件排序；未完全符合的品種說明差在哪，可調整的差距給出「如果……就可以」的建議
3. **地圖卡片**：附近的公園、動物醫院、24 小時急診，依環境規則加減分並說明原因（台北市）
4. **追問**：挑「最能縮小範圍」的問題，例如「家裡有人對毛過敏嗎？」，回答後結果立即更新

**考慮的條件**：家庭（幼童、長輩、過敏）、費用（取得預算、每月預算）、時間（作息、每日獨處時數）、居住空間（坪數、公寓或透天）、周邊設施、個人偏好。沒提到的由追問補上。

- **有數字的條件**：「每月預算一萬」與各品種每月花費估算比較；「晚上 7 點下班」推算獨處時數，與品種可獨處時數比較；「住 15 坪」對應適合的體型（門檻為組內建議值，待專家審核）
- **家庭成員**：幼童避開大型、易興奮或骨架細的品種；長輩避開力氣大、會暴衝的品種
- **過敏**：研究顯示沒有任何犬種能被證實是「低過敏」，因此不再把過敏等同「掉毛少」，改為追問過敏程度（不確定→建議先檢測；輕微→可考慮但需加強清潔；嚴重→誠實建議先不要養）

設計原則：只依本站資料、結果用卡片與標籤呈現（不是純文字聊天）、不做診斷與用藥建議、環境規則只提醒不排除、避免品種刻板印象（用語著重訓練與管理）、地址不儲存。

### 功能 2：品種詳細頁

- **購買管道**：不推薦個別業者；提醒要求出示特定寵物業許可證，並連到政府合法業者名冊
- **領養管道**：收容所沒有該品種時如實說明，再以預設收合方式提供體型、年紀相近的收容動物
- 兩欄版面與用詞對等，選擇交給使用者

### 功能 3：AI 品質評估

- 約 50 題測試題自動評分：輸入理解（含預算、作息、坪數）、句子轉標籤、追問、問答、法規題、過敏題、環境規則
- **過敏題**與法規題同等級：AI 宣稱任何品種「低過敏」即判定失敗
- **與通用 AI 的對照實驗**：同一份題目比較台灣在地資訊正確率、常見迷思（如「低過敏犬種」）、附來源比例、拒答正確率等
- 依據：史丹佛大學研究指出採 RAG 的專門 AI 錯誤較通用 AI 少、但仍非零，因此主張「減少錯誤」而非零錯誤，結果如實呈現

### 延伸 A：領養通知

- 在推薦結果或品種頁點「有符合的動物時通知我」，設定縣市、狗或貓、體型、年紀、性別、是否絕育或指定品種，留下 Email
- 每天比對收容所新上架動物，一天最多寄一封摘要（附照片與收容所連結），可隨時取消訂閱
- **進階版**：收容動物品種欄位多為「混種」，因此由 AI 判斷照片外觀是否像指定品種；先支援外觀明顯的品種（貴賓、柴犬、柯基），用語為「外觀像」，準確率納入功能 3 測試
- MVP 採 Email；LINE Messaging API 列為加分項（LINE Notify 已於 2025 年 3 月底結束服務）

### 延伸 B：考慮清單

- 品種卡片點「☆ 加入考慮清單」，清單頁將 2–4 個品種並排比較（特徵、費用、購買與領養）
- 可**分享連結**給家人，或用瀏覽器「列印成 PDF」
- 不需要會員系統：清單存在瀏覽器，分享時把內容放進網址

### AI 的角色
- **負責**：判斷輸入類型、句子轉標籤、挑選追問、產生「如果……就可以」說明、依資料庫回答問題（RAG）、辨識地點、辨識收容動物照片外觀（延伸 A 進階版）
- **不負責**：產生品種資料 —— 資料一律來自自建資料庫，避免錯誤資訊
- **備案**：關鍵字比對與範本回答，AI 失靈時仍可運作

## 法規與風險

- **禁養犬種**：比特犬全面禁養，不收錄
- **危險犬種**：日本土佐犬、紐波利頓犬、阿根廷杜告犬、巴西菲勒犬、獒犬，若收錄須標示法規限制
- **購買管道**：犬隻買賣須有特定寵物業許可證；不自行推薦業者，改提供辨識提醒並連到政府合法業者名冊
- **免責聲明**：本站不參與交易；內容僅供參考，不取代獸醫或收容所評估

## 範圍

- **第一階段（本專題）**：狗約 15–20 種、貓約 10 種；功能 1–3、延伸 A、B；收容所 API 串接
- **第二階段**：健康管理、地圖附加圖層（寵物餐廳、美容院）、LINE 通知、會員系統
- **未來擴充**：小型哺乳類、魚類、鳥類、爬蟲類、昆蟲（資料庫設計為「物種類別＋通用標籤＋類別專屬標籤」＋法規狀態欄位）

| 角色 | 人數 | 負責 |

| AI／後端 | 1–2（有程式背景） | 寵物配對 AI（輸入判斷、追問、RAG）、AI 品質評估與對照實驗、後端架構（品種資料庫、收容所 API）、延伸 A 每日比對與寄信、照片辨識 |
| 前端 | 2 | 輸入框與結果頁（品種卡片、條件標籤、追問、回答、地圖卡片）、品種詳細頁、延伸 A 訂閱頁、延伸 B 考慮清單與 PDF 版面 |
| 環境評估 | 1 | 地圖與周邊設施資料、環境規則表、合法業者名冊整理 |
| 資料 | 1 | 品種資料、標籤、價格、照顧內容、測試題目、照片辨識用的標記照片 |

第 5 週檢查進度，落後時依序縮減：① 延伸 A 照片辨識 ② 延伸 A 移到第二階段（保留延伸 B）③ 地圖卡片改為文字清單 ④ 「如果……就可以」改為只顯示不符合條件 ⑤ 問答限定熱門品種。推薦與追加條件、品種詳細頁、品質評估（含對照實驗）、問答的護欄與附來源不縮減。
