# 🐾 Pet Connect｜寵物配對（測試版）

> 養寵物前的決策工具：用一句話描述生活條件，找出適合的狗或貓，並比較「購買」與「領養」。
> 課堂專題｜AI 軟體工程｜範圍：台灣、狗與貓

⚠️ **本版本為小組討論用的測試版（Prototype）**。所有品種資料、價格、收容數量與環境資料皆為**示意資料，尚未查證**，不可作為實際飼養依據。

## 快速開始

不需要安裝任何東西，直接用瀏覽器開啟 `index.html` 即可（單一檔案，無外部相依）。

```bash
git clone https://github.com/Ruijun711/pet_connect.git
cd pet_connect
# 直接雙擊 index.html，或：
start index.html      # Windows
open index.html       # macOS
```

## 測試版功能對照（對應 brief 第 6 節）

| 分頁 | brief 功能 | 測試版做法 | 正式版要做的 |
|---|---|---|---|
| ① 搜尋配對 | 6.1 搜尋＋追加條件 | 關鍵字比對把句子轉成標籤；條件以標籤顯示、可點擊移除；無完全符合時顯示「最接近的結果」與不符合的條件 | 由 AI 解析句子（關鍵字比對保留為備案） |
| 品種詳細頁（點卡片開啟） | 6.2 品種詳細頁 | 特徵分數、優缺點、照顧指南、一次性費用與每年開銷 | 品種資料庫、查證後的照顧內容 |
| 品種詳細頁內 | 6.3 購買與領養比較 | 並列比較表；收容所沒有該品種時顯示「相近的收容動物」 | 串接政府「動物認領養」API、合法業者許可證字號 |
| ④ 環境評估 | 6.4 地圖環境評估 | 選情境或勾選周邊條件 → 套用規則表（R1–R7）→ 加減分與提醒，並套用到搜尋結果 | Google Geocoding + OSM + 臺北市動物醫院開放資料 |
| ⑤ AI 顧問 | 6.5 AI 寵物顧問（RAG） | 規則模擬：只回答收錄品種、附來源；超出範圍或醫療問題回覆「無法回答」 | LLM + 檢索品種資料庫與農業部照護指南 |
| ⑥ 品質評估 | 6.6 AI 品質評估 | 13 題範例測試（標籤／顧問／法規），自動計算標籤正確率、附來源比例、法規題正確率 | 擴充到約 50 題，每次改模型或提示詞後重跑 |
| 📋 待決事項 | 14 待決事項、12 分工 | 列出尚未決定的項目與分工建議 | — |

每個分頁底下都有「🗣 討論點」區塊，列出該功能需要組內決定的問題。

## 示意資料內容

- 品種：狗 15 種、貓 7 種（含米克斯），分數 1–5
- 標籤：新手友善、體型、掉毛、黏人、吠叫／叫聲、運動量、適合小孩、適合長輩、適合公寓、價格、短鼻（怕熱）
- 費用：每年開銷以農業部平均（犬 14,144 元、貓 13,026 元）× 體型係數估算（係數為示意）
- 法規：輸入「比特犬」會顯示禁養提醒，不收錄

## 建議討論流程

1. 每人實際操作一次各分頁（約 10 分鐘）
2. 依各分頁的「🗣 討論點」逐項討論
3. 對照「📋 待決事項」確認負責人與期限
4. 決定技術棧後，以本測試版的畫面與資料結構作為正式版起點
